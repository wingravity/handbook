# Programming at Wingravity

At Wingravity, every developer owns their work from start to finish. Whether it's writing code, testing, or presenting a demo, you're empowered to take the lead. We believe great software comes from clear communication, collaboration, and continuous feedback.

## Own your code

You’re responsible for ensuring your code is clean, well-tested, and production-ready. Testing isn’t an afterthought, it’s part of the process. Automated tests help us move fast without breaking things.

## Keep it simple

Simplicity is key. Solve today’s problem without over-engineering for tomorrow. Simple code is easier to understand, maintain, and extend.

## Get rapid feedback

Short feedback loops drive better decisions. Whether it's through automated tests, code reviews, or user feedback, we aim to catch issues early and adjust quickly.

## Maintain a sustainable pace

We believe in working at a pace that allows us to do our best work without burning out. Consistency beats intensity in the long run.

## Show your work

Knowing how to present your work is just as important as writing it. Whether it’s a quick walkthrough or a full demo, you should be able to explain your code clearly and confidently.

## Speak up

If something doesn’t look right or could be improved, say so. We value open dialogue, whether it's about code quality, design decisions, or process improvements.

## Collaborate early and often

Pair programming, code reviews, and collective ownership help us catch issues early and build better solutions together.

## Iterate and improve

Software is never “done.” We embrace small, frequent releases, allowing us to adapt and refine as we go.

At the end of the day, it’s about delivering high-quality software while supporting each other as a team. So take pride in your work, stay curious, and don’t be afraid to challenge the status quo.
